## Codex downloads (manual)

The FlyWire Codex download portal (<https://codex.flywire.ai/api/download>) requires a
Google sign-in and acceptance of the FlyWire terms. FlyMind never automates it.
Download files yourself and run `uv run flymind data import <folder>`; files are
recognised from their header rows, not their names:

| Recognised role | Required header columns |
|---|---|
| `codex_neurons` | `root_id, group, nt_type, nt_type_score` |
| `codex_classification` | `root_id, flow, super_class, class, sub_class, side` |
| `codex_cell_types` | `root_id, primary_type` |
| `codex_connections` | `pre_root_id, post_root_id, neuropil, syn_count, nt_type` |
| `codex_coordinates` | `root_id, position, supervoxel_id` |
| `codex_names` | `root_id, name, group` |
| `annotations_tsv` | `root_id, supervoxel_id, pos_x, super_class, cell_type, top_nt` |
| `shiu_completeness` / `shiu_connectivity` | Shiu et al. formats |
| `zenodo_root_ids`, `zenodo_neuropil_pre` | Zenodo formats |

`labels.csv` (contains FlyWire contributors' names and affiliations) is recognised and
deliberately **not** imported.

## Canonical representation

`data/processed/<dataset_id>/` holds `manifest.json` (provenance: files and SHA-256,
licence, citations, transformations, filters, sign policy, counts, software versions),
`neurons.parquet`, `edges.parquet` (aggregated, sorted), memory-mappable CSR arrays
(`csr_*.npy`), optionally `connections.parquet` (per-neuropil rows), and
`validation_report.{json,md}`.

### Identifier handling

FlyWire root IDs (e.g. `720575940660219265`) exceed 2⁵³ and are corrupted by float64.
They are parsed from text as int64, rejected if not purely integer, stored as int64,
and sent to browsers as **strings**. Validation includes a float-corruption detector
(low-bit distribution test). The dense `idx` (sorted by root ID) is a storage detail.

### Transformations applied to the v783 bundle

* `cell_type` = annotation `cell_type`, falling back to `hemibrain_type` (as Codex's
  consolidated type does); `hemibrain_type` is kept separately.
* Transmitter labels normalised (`acetylcholine` → `ACH`, …); confidence kept.
* Annotation positions converted from 4×4×40 nm voxels to nm.
* `primary_neuropil` = neuropil with most output synapses (Zenodo table), ignoring the
  unassigned buckets `None`/`UNASGD`; neurons without presynapses in the brain have none.
* Edges from the Shiu table re-indexed by root ID; Shiu's own index columns ignored;
  signs preserved verbatim. 616 v783 neurons are absent from the Shiu neuron list and
  have no connections in this source (recorded in the manifest).
