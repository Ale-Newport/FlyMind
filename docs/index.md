# FlyMind

FlyMind is a virtual *Drosophila* laboratory: a reproducible leaky integrate-and-fire
simulation of the FlyWire whole-brain connectome (**Brain Simulator**), the
NeuroMechFly body in MuJoCo driven through a documented neural–motor interface
(**Virtual Fly**), and an interactive 3D view of 139,255 reconstructed neurons
(**Brain Explorer**), integrated in one experiment workspace.
